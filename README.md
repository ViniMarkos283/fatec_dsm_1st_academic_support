# Fatec DSM — 1st Semester Academic Support

## Sobre o projeto
Este repositório reúne materiais complementares de estudo
voltados aos alunos do primeiro semestre do curso de
Desenvolvimento de Software Multiplataforma (DSM) da Fatec.

## Objetivos
- Facilitar a revisão dos conteúdos apresentados em aula.
- Disponibilizar exemplos práticos e códigos comentados.
- Auxiliar na compreensão de conceitos e exercícios.
- Incentivar o estudo independente e a colaboração.

## Organização do repositório
Os materiais estão organizados por disciplina e data da aula, facilitando a localização dos conteúdos estudados.

```text
fatec_dsm_1st_academic_support/
├── Algoritmos/
│   ├── Aula [AAAA-MM-DD]/
│   │   ├── script.py
│   │   └── anotacoes.md
│   └── Aula [AAAA-MM-DD]/
│       └── exercicios_beecrowd.py
├── Desenvolvimento Web I/
│   └── Aula [AAAA-MM-DD]/
│       ├── index.html
│       └── script.js
└── Modelagem de Dados/
    └── Aula [AAAA-MM-DD]/
        ├── diagrama.png
        └── script.sql
```

### Como localizar os materiais
1. Acesse a pasta da disciplina desejada.
2. Localize a pasta da aula pela data no formato `AAAA-MM-DD` (ano, mês e dia).
3. Abra os arquivos correspondentes ao conteúdo daquela aula.

Cada pasta de aula reúne os arquivos relacionados ao respectivo dia, como códigos-fonte, exercícios, scripts SQL, diagramas e anotações, conforme o conteúdo trabalhado.

**Observação:** os nomes dos arquivos apresentados na estrutura são exemplos ilustrativos. Os conteúdos disponíveis variam conforme cada aula.

Os comentários estão disponíveis para dúvidas, sugestões e correções relacionadas ao conteúdo das anotações.

Para manter o ambiente útil para todos:

* Mantenha os comentários relacionados ao conteúdo acadêmico.
* Ao apontar um erro, indique o trecho e, se possível, sugira uma correção.
* Evite compartilhar informações pessoais ou publicar dados de terceiros.

As contribuições poderão ser utilizadas para melhorar os materiais de apoio.

## FAQ da turma
Esta seção reunirá perguntas frequentes dos alunos e suas respectivas respostas, com o objetivo de esclarecer dúvidas recorrentes e facilitar o acesso ao conhecimento compartilhado.

As perguntas serão selecionadas a partir das dúvidas recebidas e poderão ser respondidas diretamente nesta seção ou por meio de materiais complementares.

As dúvidas serão publicadas sem identificação dos alunos.
